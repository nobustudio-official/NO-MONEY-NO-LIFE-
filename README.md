# NO-MONEY-NO-LIFE-
ブラウザ版のNO MONEY, NO LIFE

## スマホでのPCレイアウト表示

スマホでは通常の `index.html` から `game-viewport.html` に自動的に入り、
同じゲーム本体を1つのフレーム内で実行します。タイトルと開始設定は端末の表示サイズを保ちます。
ゲーム開始後は、既存のSP04/AN02に記載されたPC基準の **1920 × 1080** で描画し、
画面全体を縦横比を保って端末の表示領域に収めます。
852 × 393では約36.39%表示となり、ゲーム部分は約698.67 × 393、左右の余白は各約76.67です。
文字・画像・操作ボタン・各種ポップアップはすべて同じ倍率で縮小されます。

回転やブラウザーの表示領域変更では表示倍率だけを更新し、ゲーム本体を再読み込みしません。
タップ判定、マップ操作、Canvas演出はフレーム内の同じ座標系を使います。
ゲーム内の「もう一度遊ぶ」で再読み込みした場合は、元のサイズのタイトル画面に戻ります。
PCで開いた場合は従来の表示を使用します。

変更したスクリプト・CSSの読み込みURLは更新済みです。起動中のページには再読み込みが必要です。
新しいファイル2つ（`game-viewport.js` / `game-viewport.html`）も本体と一緒に配置してください。

自動チェック:

```text
node --test tests/game-viewport.test.cjs
```

このチェックは表示サイズ・開始時切り替え・回転・再読み込み・起動処理との接続を
ブラウザー環境の代替モデルで検証します。実機のSafariや実際の対戦操作・音声の検証は含みません。
