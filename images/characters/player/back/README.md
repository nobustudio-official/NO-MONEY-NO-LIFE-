# 戦闘用のプレイヤー背面素材

全12キャラクターの背面を、既存の4方向画像から透過PNGとして作成済み。

- 元画像は親フォルダーに保持。
- `<名前>-back.png` がゲーム用の単体素材。
- `manifest.json` にキャラID、元画像、切り出し情報、出力寸法、SHA-256を記録。
- 拡大縮小せず抽出。表示時は縦横比を保ち、キャラごとの大きさと足元位置を調整する。
- 2026-10-26、`battle-motion.js` を通じて通常戦闘・通常ボスの背面表示に接続済み。実画面確認待ち。

詳細: [背面画像の準備記録](../../../docs/PLAYER_BACK_SPRITES.md)
