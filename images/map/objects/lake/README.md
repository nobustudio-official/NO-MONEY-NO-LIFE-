# 小オブジェクトの受け渡し

画像はこのフォルダーに保存し、チャットで「オブジェ小の画像を工房に追加して」と指示する。
フォルダーの自動監視は行わず、合図の後に画像・透過・名前を確認して登録する。
1,000,000 bytes未満の画像は工房から直接参照する。1,000,000 bytes以上の画像は、圧縮したWebPを工房から参照し、原画像はOneDrive外へ保管する。

登録情報は `catalog.json`。ファイル名ごとに地域・絵文字・初期の幅と奥行を指定する。
地域は候補一覧の分類であり、別の地域にも配置できる。位置や倍率は工房側で変更可能。
登録時に `node scripts/import-small-objects.cjs` を実行して共通カタログへ取り込む。
PNG・WebP・JPEGに対応。今後追加した画像で指定がないものは街・初期幅180として登録し、必要なら調整する。

同名の画像の差し替えは配置を引き継ぐ。使用中の画像はファイル名を変えたり削除せず、必要な場合はチャットで相談する。
新規画像の追加は候補一覧への登録だけで、既存の配置・ルート・本番ゲームは変更しない。
更新後は工房をCtrl＋F5で再読み込みする。

圧縮済みWebPは `images/map/objects/small-objects/` に置き、`map-authoring/optimized-small-objects.json` から登録する。`filename` には元画像のファイル名を指定してIDを維持し、原画像は `Documents/NO_MONEY_NO_LIFE_Original_Images_<date>` に保管する。
