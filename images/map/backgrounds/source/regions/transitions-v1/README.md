## 修正内容

- 遺跡と雪山が共有する境界を、大陸の上げた手と耳の間のくぼみ（世界座標3028.36,1611.64）へ合わせた。雪山の海岸に遺跡が細い三角形として入り込む形を解消。
- 陸上8地域の境界付近は、同じ地面素材を透明度を変えながら重ねる。境目の濃淡に固定の細かなゆらぎを加え、雪・砂・土などが硬い直線で切り替わる見え方を和らげた。
- 元の地面の縮尺・色や石の大きさを維持。確認用の薄い区切り線はユーザー指定のため残す。
- 海岸の砂色の縁を全地域の地面より上に描き、雪や舗装で片側だけ隠れないよう統一。
- 湖は地面・区切り線より上に重なり、湖内部には陸上の境界を出さない。

## 表示負荷・容量

4世界ピクセルにつき1画素の透明度画像を制作時に計算し、ゲームでは画像を再利用する。
巨大なぼかし処理やノイズ計算をゲーム中に毎回走らせない。8ファイル計793,440バイト。
2回重ねることで下にある元の色の切り替えを弱める。地面の画像自体にはぼかしをかけない。

## 再作成

1. demos/map-lab/build-region-backgrounds.py を実行し、共有する地域輪郭を作る。
2. demos/map-lab/build-transition-masks.cjs を実行し、輪郭由来の透明度画像とlayout.jsonを作る。
3. build-region-backgrounds.py を再実行し、生成結果を本体データに取り込む。

輪郭のハッシュが一致しないマスクは自動的に無効にする。輪郭を更新したら手順2・3で作り直す。
配置や地域の広さは地域データで管理し、マス・道のIDや接続とは独立させている。

通常倍率の遺跡・雪山接続、各地域、全体表示を実ゲームHTMLで確認。開始カメラ、201マス、256接続、24通りのカメラ範囲、全素材の読み込みとブラウザエラーなしを確認済み。
